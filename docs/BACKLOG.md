## A. アセット再生成（GEMINI_API_KEY が要る／今は実行できない）

キーを環境変数に入れれば `tools/gen_anim_frames_gemini.py` で回せる。
受け入れ条件は `docs/CHARA_PROMPTS.md` の「スプライトの等身・キャンバス仕様」。
生成後は必ず `python3 tools/check_sprites.py` と `--proportions` を通すこと。

- [ ] **等身がキャラ間で 1.47倍ばらついている。** 頭幅/全高の実測は
      キリコ・ミル・ユズキ 0.391／ナース 0.344／ムュウ 0.315／**ドクター 0.266**。
      ドクターの頭は他の 2/3。並ぶと「同じ絵の世界の住人」に見えない。
      スケールでは直せない（頭だけ拡大縮小＝首の接合が破綻する）。目標帯 0.33〜0.40。
- [ ] **前面・背面のスプライトが実質存在しない。** `walk_front` / `walk_back` の中身は
      全キャラとも正面立ちポーズで、**背中が一度も見えない**。徘徊を横移動優位にして
      誤魔化しているが、奥/手前へ動く瞬間に絵が滑る。
- [ ] **経営パネルの背景アートが無い。** `shop_interior.png` は看板と垂れ幕が
      実在しない漢字（「秸乄たっリ」「浅酒程」等）だったため外した。
      720x1280 の等倍で描き直す。**文字は絵に焼かず、Label で実テキストを重ねる**
      （`hd2d_view._sign_text` と同じ作法。あちらは全て実在の字で正しくやれている）。

## B. ゲーム設計（絵ではなく手触りの問題）

- [ ] **夜営業の給仕に選択が無い。** `！` の客をタップするとチップが入るが、
      押さなくても完走する＝判断が発生しない。どの客を先に捌くかで結果が変わる形にすると、
      5分休憩に意思決定が生まれる。
- [ ] **献立4枠がほぼ一意解。** 予報と一致する皿を入れるだけで決まりがち。
      外す判断に見返りが要る（レイカのシナジー「予報外れの皿も売れる」が
      その入口になっているが、他に選択肢が無い）。
- [ ] 25分間プレイヤーがすることは無い（ポモドーロとしては正しい）。
      タップ介入は**不要と判断済み**。この行は再検討しないための記録。

## C. UI の作法が画面間で食い違う

- [ ] **`ds.gd` が一本化されていない。** ホームは角丸パネル、経営は斜めカット。
      文字サイズの段数も画面ごとに違う。まずどちらかに寄せる。
- [ ] **メンバー／市場／工房パネルが旧タイポのまま。** 今回統一したのは経営と
      共有ヘッダ/フッタだけ。
- [ ] メンバーの詳細カードがキャラ切替で瞬間差し替わる（選択バーだけ動く）。
- [ ] 押し込みモーションが `_chip`/`_btn`/`_icon`/店番カードにしか届いていない。
      工房の行・市場の品・改装ノードは沈まない（即時モード描画のため一括対応が難しい）。
