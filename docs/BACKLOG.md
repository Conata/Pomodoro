## C. UI の作法が画面間で食い違う

- [x] ~~`ds.gd` が一本化されていない~~ → 斜めカットに寄せた。改装ツリーの円ノードだけ
      形を残し、そのための `_round_panel()` を逃げ道として1つ用意した。
- [x] ~~メンバー／市場／工房パネルが旧タイポのまま~~ → ds.gd の段のみに統一。
      あわせて下端固定の結論ブロックを全画面に入れ、密度と縦の埋まり方を揃えた。
- [x] ~~ホームだけリズムが違う~~ → 調べると形の問題ではなく**数字の食い違い**だった。
      ホームの見出しは売上（約209G）、経営の結論は純益（+128G）で、同じ夜について
      違う額を約束していた。原価（MAT_COST）が menu_overlay にだけ定義され、
      ホームが知らなかったのが原因。データ層へ移して `sim.night_profit()` に一本化し、
      ホームも「手取り」を見出しにした。両画面が同じ数字を出す。
      配置そのものは変えていない（ホームは世界を見せる画面なので、
      結論ブロックで3Dを潰すのは逆効果と判断した）。
- [x] ~~改装ツリーの上下に余白が残る~~ → 格子の間隔を縦横で共通にしていたのが原因で、
      狭い方（横幅・約102px）に頭打ちされていた。行間だけ別に取るようにして解消。
      「円を捨てるか余白を許すか」の二択ではなかった。節点は円のままで、
      方向を持たないという形の意味も壊していない。
- [x] ~~装備を外す導線が無い~~ → `unequip:<girl>:<slot>` を追加。装備中の枠は「外す ▸」、
      空き枠は工房への導線に、同じ枠が状態で役割を変える。倉庫満杯時は「廃材にする ▸」と
      赤で予告する。あわせて未知の id で `GIRLS`/`SLOTS` を引いて落ちる穴を equip 側とも塞いだ。
- [x] ~~市場の背景が他画面より明るい~~ → 実測すると市場固有ではなく
      「背景アートを持つ3画面（地の明るさ 11〜12）と持たない2画面（7.6〜7.8）」の差だった。
      アートのある画面だけ暗幕を 0.64→0.74 に強めた（工房 12.0→8.9）。
      メンバーと市場は 11 前後のまま：これ以上暗くすると絵が泥になるので、
      「UIの背後に世界がある」意図を優先して止めた。
