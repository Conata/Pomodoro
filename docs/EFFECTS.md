# 演出の棚卸し（黒猫飯店）

ゲーム内で「何かが起きた」と伝えるべき瞬間の全リスト。実装状況と、
**作るのか外部から持ってくるのか**の判断を書く。2026-07-28 時点。

---

## 結論：視覚エフェクトは全部「作る」、音は「もう持っている」

**外部アセットは使わない。** 理由は3つ。

1. **ピクセル密度とパレットの規律が壊れる。** このセッションで最も効いた規律が
   「1テクセルあたりの画面pxを混ぜない」「有彩色は識別色1つ＋状態色まで」だった。
   配布されているVFXパックは各々の密度とパレットを持っているので、混ぜた瞬間に
   HD-2Dは安く見える。ここは妥協点が無い。
2. **既存の演出が全て手続き描画。** `draw_colored_polygon` / `draw_circle` /
   `draw_texture_rect` で毎フレーム描いている。解像度に依存せず、パレットの色を
   そのまま使え、アセットの読み込みも要らない。スプライトシートを混ぜると
   この一貫性が切れる。
3. **そもそも取得できない。** この実行環境のネットワークポリシーは
   kenney.nl / opengameart.org / godotengine.org/asset-library をいずれも
   403 で拒否する（`$HTTPS_PROXY/__agentproxy/status` で確認）。
   `raw.githubusercontent.com` だけは通るが、素性とライセンスの確認が要るものを
   規律を壊してまで入れる理由が無い。

**音は話が別。** 音は密度もパレットも持たないので外部素材と相性がいい。
ただし**この作品には既に11種の効果音が同梱されていて、5種しか鳴らしていない**。
買う前に配線する。

| 同梱されている音 | 使用状況 |
| --- | --- |
| `chest_open` `thunder` `ui_buy` `ui_confirm` `ui_denied` | 鳴っている |
| `damage` `enemy_death` `slash` `sword` `fire` `teleport` `ui_equip` | **一度も鳴っていない** |

## 優先順位

1. **#21 箱開封の作り直し。** 25分集中した見返りを受け取る瞬間が、いま一番弱い。
   レア度で演出の格を変え、間を作り、9個目以降を捨てない。
2. **音の配線。** 眠っている7種を#7〜#10・#32へ繋ぐだけで、潜航の手応えが変わる。
   新しく要るのは「レベルアップ」「共鳴獲得」「レア入手」の3つ程度。
3. **#16 装備発見／#17 記憶のかけら。** 潜航中の拾得が全部ログ行で流れている。
4. **#33 工房の大成功。** 確率で当たる要素に演出が無いのは損。
5. **#5 集中開始の儀式。** 25分の始まりに区切りを与える。
