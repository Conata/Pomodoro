# 演出の棚卸し（黒猫飯店）

ゲーム内で「何かが起きた」と伝えるべき瞬間の全リスト。実装状況と、
**作るのか外部から持ってくるのか**の判断を書く。2026-07-28 時点。

---

## 結論：視覚エフェクトは全部「作る」、音は「もう持っている」

**外部アセットは使わない。** 理由は3つ。

1. **ピクセル密度とパレットの規律が壊れる。** このセッションで最も効いた規律が
   「1テクセルあたりの画面pxを混ぜない」「有彩色は識別色1つ＋状態色まで」だった。
   配布されているVFXパックは各々の密度とパレットを持っているので、混ぜた瞬間に
   HD-2Dは安く見える。ここは妥協点が無い。
2. **既存の演出が全て手続き描画。** `draw_colored_polygon` / `draw_circle` /
   `draw_texture_rect` で毎フレーム描いている。解像度に依存せず、パレットの色を
   そのまま使え、アセットの読み込みも要らない。スプライトシートを混ぜると
   この一貫性が切れる。
3. **そもそも取得できない。** この実行環境のネットワークポリシーは
   kenney.nl / opengameart.org / godotengine.org/asset-library をいずれも
   403 で拒否する（`$HTTPS_PROXY/__agentproxy/status` で確認）。
   `raw.githubusercontent.com` だけは通るが、素性とライセンスの確認が要るものを
   規律を壊してまで入れる理由が無い。

**音は話が別。** 音は密度もパレットも持たないので外部素材と相性がいい。
最初に調べた時点では**同梱の11種のうち5種しか鳴らしていなかった**ので、まず配線した。
その後、足りない分を Kenney の CC0 パックから19本取り込んだ
（`tools/import_kenney_sfx.py` と `assets/third_party/CREDITS.md` に出どころを記載）。

アセットストア本体（kenney.nl / opengameart.org / itch.io / Godot Asset Library）は
この環境のネットワークポリシーが 403 で拒否するが、**GitHub は通る**ので、
CC0 パックの Godot 向けミラーから `git clone` で取得した。

現在の総発音数は1日ぶん（潜航25分→浮上→夜営業→精算）で **387発**。
種類ごとのクールダウンと「格上を鳴らしたら格下を黙らせる」規則は
`main.gd` 末尾の内部クラス `SfxRouter` に集約してある。

残り：

1. **音量・ミュート設定が存在しない。** ブラウザのタブミュートに頼っている。
   1日387発鳴るようになった以上、これは必須。`SFX_BASE_DB` の1定数と
   `SfxRouter` の `vol` に集約してあるので、設定を足す先は決まっている。
2. **音量バランスは実聴で詰めていない。** 頻度が高いほど絞る方針で決めた机上の値に、
   発音回数の実測を突き合わせただけ。とくに `pickup` は25分で41発と多く、
   `-14dB` で地の音より下に置いてあるが実機で気になる可能性がある
   （調整点は `CD_LOOT`）。
3. **視覚がまだ文字だけの瞬間。** #16 装備発見・#17 記憶のかけら・#33 工房の大成功は
   音が付いただけで、画には物が出てこない。#38 ストリークも数字のまま。
4. **#5 集中開始の視覚。** 音は付いたが、画面フェードのみで儀式になっていない。
5. **`main.sfx_counts` を本番コードに残している。** 発音回数を実測できる状態を
   保つための辞書1本。不要になれば1行で消せる。
